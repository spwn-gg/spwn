## What is spwn?

Claude Code is a single conversation in a single terminal. Real work isn't linear:
you want to try an idea one way, try it another, run a few agents at once, and keep
whichever result is best. Doing that by hand means juggling git worktrees, terminal
tabs, and copy-pasted context — and losing running work every time a window closes.

**spwn is a native macOS app that makes that the default.** Every Claude session runs
on **its own git branch, in its own isolated copy of your code**, so several can run at
the same time — even unattended — without clobbering each other or your working tree.
Sessions keep running after you close the app, and you merge back only what you want to
keep.

Sessions also **survive restarts** — quit spwn, reopen it, and every session is right
where you left it, running programs and all. And a Claude session is the real thing: a
clean, scrollable conversation on one side and full Claude Code — every slash-command
and tool prompt — on the other.

## Why not just do this by hand?

You can wire up git worktrees, tmux, and a prompt library yourself. spwn is what you'd
build if you did — and then maintained:

| Doing it by hand | With spwn |
|---|---|
| `git worktree add` + branch per experiment, cleaned up manually | A branch + worktree per session, created and removed for you |
| Cold `npm install` / rebuild in every worktree | Heavy build dirs COW-cloned in — build instantly |
| Re-paste project background into each new chat | A **Merge tray** you Inject in one click |
| Lost running work when a terminal closes | Sessions survive quitting the app |
| Per-branch setup scripts you run by memory | **Project hooks** fire on session lifecycle events |
| Merge experiments back and hope you cleaned up | One-click **Merge**, with a dialog naming anything you'd lose |
